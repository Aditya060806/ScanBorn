## What is now present

Dashboard and native Android share `dashboard/shared-viewer`. The backend serves immutable,
ID-scoped reconstruction previews and preserves imported faces separately from navigation's
canonical cloud. Native Spaces performs the scan-to-mission workflow and keeps stop controls
outside WebView. Android assets are generated by `npm run build:viewer` during Gradle preBuild.

Capture uploads use stable IDs, bounded durable queues and explicit partial completion.
Library persistence no longer depends on ignored application sources. Exported int8 artifacts
are independently re-evaluated and tied to checksums, mission and robot-spec snapshots.
Jobs/request results survive restart, interrupted jobs are explicit, and drives never auto-resume.

Calibration is now asynchronous in firmware, fake rover and orchestration. Dashboard experiments
retain native HTTP stop controls, require measurement before application, verify configuration
read-back, and attempt rollback when verification fails. Fake-derived configuration writes only
to `SCANBORN_DATA/simulated-specs`; it cannot mark the physical spec calibrated. Noise remains
assumed. Completed firmware measurements are frozen rather than changing with later odometry.

Rescan now requires `same_marker_confirmed: true`; the dashboard offers an explicit checkbox,
and Python SDK callers pass `same_marker_confirmed=True`. Unknown alignment cannot silently
invalidate missions. Legacy blocking `/calibrate` returns 410 with migration guidance.
