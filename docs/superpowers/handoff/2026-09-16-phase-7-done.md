## 4. New traps

- **CRLF everywhere.** Many working-tree files are CRLF. Patch with a script that reads
  `newline=""`, replaces exact strings and writes the same endings back; write the script with the
  Write tool, because a Bash heredoc mangles `\\`.
- **`git rm` stages.** Delete with `rm` so the index stays as the owner left it.
- **`adb devices` may show `offline`** right after connecting: `adb reconnect offline`, then
  `adb wait-for-device`.
- **Robot kinds are `sim`, `fake_rover`, `rover`.** Old databases can still contain `unoq` rows.
